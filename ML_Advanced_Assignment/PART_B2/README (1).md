# Sparse Modeling for High-Dimensional Data

This project studies regression when the number of features exceeds the number of samples (`p > n`).

## Questions covered
1. Demonstrate OLS overfitting/instability when `p > n`.
2. Compare Ridge, Lasso, and ElasticNet using nested cross-validation.
3. Measure Lasso feature-selection stability across bootstrap resamples.
4. Recommend a regularization method based on measured performance and stability.

## Dataset
A reproducible synthetic gene-expression-style dataset is generated by `main.py`:
- 90 samples and 300 features (`p > n`)
- 10 known signal features
- Two blocks of correlated features
- Noise in the target
No download is required.

## Setup and run
Python 3.9+ recommended.

```bash
pip install -r requirements.txt
python main.py
```

## Outputs
- `outputs/Q1_OLS_p_greater_n/` — OLS vs Ridge metrics, plot, and summary
- `outputs/Q2_Nested_CV_Comparison/` — nested CV fold metrics, model comparison, plot, and summary
- `outputs/Q3_Bootstrap_Feature_Stability/` — selection frequencies, coefficient records, plot, and summary
- `outputs/Q4_Final_Recommendation/` — final recommendation summary
- `outputs/overall_summary.txt` — combined report
- `outputs/final_recommendation.txt` — standalone recommendation

## Method notes
- StandardScaler is included inside model pipelines to avoid preprocessing leakage across CV folds.
- Nested CV uses 5 outer folds and 4 inner folds. Outer scores estimate generalization; inner scores tune hyperparameters.
- Bootstrap sampling draws rows with replacement. Lasso alpha is fixed during stability analysis.
- Feature selection frequency measures stability, not causality.
